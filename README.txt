Control your Tuiss SmartView blinds directly from your Homey Pro over Bluetooth, without a separate remote control. Open, close and set the position in the Homey app or use your blinds in Flows. Reverse direction lets you match the controls to your blind. Experimental motor-limit setup is available under the blind device Settings → Maintenance → Set limits; complete both endpoints and verify their movement. Interrupted setup requires configuring both endpoints again.

For the full illustrated installation and setup guide, see README.md in the GitHub repository aberkel/Tuiss-SmartView-Homey-Pro, available through the app's website or source link. This independent community app is not affiliated with Tuiss. Successful end-to-end motor calibration has not yet been confirmed.
